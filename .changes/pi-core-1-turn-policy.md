titulo: Atualizações de dependências preservam as políticas de execução e telemetria

Os agentes continuam respeitando a política de parada, o limite de turnos e a contabilização de uso após a atualização para Pi Agent Core 1.0. Instruções pendentes permanecem sem confirmação quando o limite já foi alcançado.

A configuração do Sentry acompanha a versão 11 preservando a política anterior de coleta e os hooks de remoção de dados sensíveis.
